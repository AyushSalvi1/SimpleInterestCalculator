# Simple Interest Calculator

A lightweight, open-source bash script to calculate **simple interest**, built to help a micro-finance startup transition its codebase from Subversion (SVN) to Git and GitHub.

## 📖 About the Project

This project provides a simple, easy-to-use Bash script that calculates simple interest based on user-provided principal amount, interest rate, and time period. It was created as part of the company's initiative to modernize its version control workflow by migrating from SVN to Git, while also embracing open-source best practices such as clear documentation, contribution guidelines, and a code of conduct.

Our mission is to empower and provide opportunities to low-income individuals by building simple, transparent, and accessible financial tools.

## ⚙️ Features

- Calculates simple interest using the formula:

  ```
  Simple Interest (SI) = (Principal × Rate × Time) / 100
  ```
- Takes user input for Principal, Rate, and Time via the command line
- Displays the calculated interest and total amount
- Lightweight and dependency-free — runs on any system with Bash

## 🚀 Getting Started

### Prerequisites

- A Unix-based system (Linux/macOS) or WSL on Windows
- Bash shell installed (pre-installed on most systems)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/simple-interest-calculator.git
   ```
2. Navigate into the project directory:
   ```bash
   cd simple-interest-calculator
   ```
3. Make the script executable:
   ```bash
   chmod +x simple_interest.sh
   ```

### Usage

Run the script from the terminal:

```bash
./simple_interest.sh
```

Follow the on-screen prompts to enter:
- Principal amount
- Rate of interest (%)
- Time period (in years)

The script will output the calculated simple interest and the total amount.
